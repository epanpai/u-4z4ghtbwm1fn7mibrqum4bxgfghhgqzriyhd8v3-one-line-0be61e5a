## The entry

> I asked my smart speaker for a joke. It paused, sighed, and said, 'Have you tried being funnier?'

A smart speaker that roasts its owner: a setup that sounds like a normal request, a beat of hesitation ("paused, sighed"), then the twist — the device turns the joke back on the person who asked for it. The punchline lands on the last word.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–140 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
